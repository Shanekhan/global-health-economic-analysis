# Global Health & Economic Analysis

## 📌 Project Overview
This project analyzes the relationship between economic indicators, health expenditure, mortality rates, food prices, and crime (homicide rates) across countries from 2000 to 2023.

The goal is to understand how socio-economic factors influence public health outcomes at a global scale.

---

## 📊 Datasets Used

- World Bank Mortality Data  
- World Bank GDP per Capita  
- World Bank Health Expenditure  
- World Bank Homicide Rate  
- World Food Programme (WFP) Food Prices  

---

## 🛠️ Data Processing Steps

1. Loaded multiple raw datasets from different sources  
2. Cleaned and standardized formats  
3. Converted wide-format data into long format  
4. Removed aggregated regions (kept only real countries)  
5. Handled missing values and inconsistencies  
6. Aggregated food price data to country-year level  
7. Merged all datasets into a unified dataset  
8. Performed sanity checks and validation
